# 绩效 · 使用指南

> 入口：左侧菜单"绩效助手"

## 当前评估流程

本系统采用**两级评估**：**自评 → 上级评**。流程极简，便于全员落地。

```
HR 发起考核 → 员工自评 → 直属上级评 → 系统加权计算最终分 → 部门汇总 → 反馈面谈
```

## 1. 指标库（`/performance/indicators`）

- HR 在此维护"业绩 / 能力 / 态度 / OKR"四类指标。
- 每条指标包含：名称、权重建议、打分方式（百分制 / 五分制 / ABCD）、说明。
- 指标会被复用到不同模板。

## 2. 发起考核（`/performance/assessments/new`）

1. 选择模板（如"季度通用模板"）或临时编辑指标 + 权重。
2. 选择评估周期（如 `2026-Q1`）和适用员工（按部门或单选）。
3. 设置截止日：自评截止日 / 上级评截止日。
4. 点击"发起" → 钉钉自动通知所有被评估人。

## 3. 评估列表（`/performance/reviews`）

不同角色看到不同内容：

- **员工**：仅看本人，状态为"自评中"时点击进入填写。
- **经理**：看到下属的列表，状态为"上级评中"时进入打分。
- **HR**：全部，可监控完成率、催办、调整截止日。

## 4. 自评 / 上级评

- 自评页面左侧为指标列表，右侧打分 + 评语；支持暂存草稿。
- 自评提交后状态变为"上级评中"，员工不可再修改。
- 上级评页面会显示"自评分 + 自评说明"作为参考，避免拍脑袋。
- 上级提交后系统按权重计算最终分并落定等级（S/A/B/C/D）。

## 5. 部门汇总（`/performance/department-summary`）

- 按部门聚合本周期：参与率、完成率、平均分、等级分布饼图。
- 列出"高绩效 TOP 3"和"需关注（最低 3 名）"，方便经理面谈准备。
- 支持导出为 Excel 或 PDF 用于管理会汇报。

## 6. 看板（`/performance`）

- 周期选择 → 全公司参与率、完成率、各部门平均分对比柱状图。
- 历史周期对比，看团队是否在持续提升。

## 最佳实践

- 自评不要空填——系统检测连续相同分数会提示"请提供具体事例"。
- 上级评建议在自评提交后 3 天内完成，及时性影响员工体验。
- 部门汇总数据用于"组织盘点会"，不直接展示给员工本人，仅用于决策。
