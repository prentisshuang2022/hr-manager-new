# 考勤 · 使用指南

> 入口：左侧菜单"考勤助手"

## 1. 总览（`/attendance/overview`）

- 顶部 4 个 KPI：应到、实到、异常、加班时长。
- 中部"今日考勤热力图"按部门 × 时段展示打卡密度，红色为异常聚集区。
- 下部异常清单可一键"通知补卡"。

## 2. 考勤明细（`/attendance/detail`）

- 选择日期范围 + 部门，查看每天每个员工的打卡记录。
- 支持"按异常类型筛选"：迟到 / 早退 / 缺卡 / 漏打。
- 点击单元格可弹出"门禁记录回看"，辅助判定是否需要补卡。
- 右上角"上传考勤"支持 Excel 批量补录（外勤/特殊场所）。

## 3. 加班与请假（`/attendance/overtime`）

- 顶部 Tab 切换"加班 / 请假"。
- **加班**：列表展示申请记录，经理可"批准/驳回"，HR 可"批量结算调休"。
- **请假**：员工提交后，按假期类型（年假/事假/病假/调休）扣减余额。
- "余额查询"抽屉可看到员工各类假期剩余天数与有效期。

## 4. 规则配置（`/attendance/rules`）

- 仅 HR 可访问。
- 新建规则：选择适用范围（公司/部门/个人）→ 工作日 → 上下班时间 → 容迟分钟 → 加班最小时长。
- 规则可启用/禁用，禁用后该范围内不再产生新异常。

## 5. 异常处理（`/attendance/exception/:id`）

- 异常详情页展示：原始打卡、规则比对、可选处理动作（补卡 / 标记出差 / 标记请假 / 不计异常）。
- 处理后保留操作日志（操作人、原因、时间）。

## 最佳实践

- 每周一上午统一处理上周异常，钉钉提醒员工本人 24 小时内补卡。
- 节假日前一周更新"加班规则"中的节假日加班倍率。
- 经常出差的岗位绑定专门规则（弹性打卡、外勤免打卡）。
