# 招聘 · 使用指南

> 入口：左侧菜单"招聘助手"

## 1. JD 管理（`/recruitment/jobs`）

- 列表按"招聘中 / 已暂停 / 已关闭"分组，显示在招人数 / 已入职 / 在面。
- 点击"新建 JD"（`/recruitment/jobs/new`）：
  1. 填写岗位、部门、编制、薪资范围。
  2. JD 正文支持 **AI 生成**：输入 3-5 条核心要求，自动生成 markdown JD。
  3. 选择发布渠道（BOSS / 猎聘 / 内推 / 官网）→ 一键发布。

## 2. 简历库（`/recruitment/resumes`）

- 支持拖拽上传 PDF/Word，单次最多 50 份。
- 上传后 AI 自动解析为结构化字段（姓名、学校、工作年限、期望薪资等），并打标签。
- 解析失败的简历显示重试按钮。
- 列表顶部支持"按 JD 智能匹配"：选择某个 JD，按匹配分排序。

## 3. 候选人台账（`/recruitment/candidates`）

- 漏斗视图展示各阶段人数：待筛选 → 已邀约 → 面试中 → Offer → 已入职 / 已淘汰。
- 点击数字下钻到该阶段候选人列表。
- 候选人详情（`/recruitment/candidates/:id`）：
  - 简历预览 + AI 摘要 + 匹配分。
  - 面试时间轴：每轮面试官、时间、结果、反馈。
  - 阶段操作按钮：推进 / 淘汰 / 待定。

## 4. 面试与 Offer

- "安排面试"：选择面试官（可多选）→ 时间 → 类型（电面/视频/现场），系统自动发送钉钉日历邀请。
- 面试官在手机端提交反馈（通过/不通过 + 评语），即同步到候选人时间轴。
- "发 Offer"：录入薪资 + 入职日期，生成 Offer PDF 并发邮件，候选人在线确认。
- "已入职"会自动在【员工档案】生成新员工记录，避免重复录入。

## 5. 招聘看板（`/recruitment`）

- 漏斗转化率、各渠道有效简历数、平均周期、招聘负责人 TOP。
- 用于月度招聘复盘。

## 最佳实践

- 每周一刷新"待筛选"队列，超过 3 天未处理会自动告警。
- Offer 接受率低于 60% 时，复盘"薪资带宽"或"面试体验"。
- 内推简历单独打标签，方便兑现内推奖金。
