# 培训 · 使用指南

> 入口：左侧菜单"培训助手"

## 整体流程

```
材料上传(分类) → AI 出题 → 组卷考试 → 自动判分 → 不及格补考
        ↘ 在岗培训：节点推进 → (需确认时) 学员确认 → 下一节点 → 完成归档
```

## 1. 题库管理（`/training/question-bank`）

### 1.1 上传培训材料（支持类型）

在"上传材料"区先选择**材料类型**，不同类型走不同处理：

| 类型 | 适用场景 | 接受格式 | AI 处理 |
| --- | --- | --- | --- |
| 视频 | 高管培训、产品宣讲 | MP4 / MOV / WebM | 自动转写 + 抽取知识点 + 生成题目 |
| 操作手册 | 系统/设备使用 | PDF / Word | 按章节生成单选 + 简答 |
| SOP | 标准作业流程 | PDF / Word / Markdown | 按步骤生成判断 + 单选 |
| 文档 | 通用资料 | PDF / Word / TXT | 通用解析 |

操作步骤：

1. 选择类型卡片（高亮表示已选中）。
2. 拖拽或点击上传区域选择文件，提示文案会随类型变化。
3. 上传后列表显示"待解析 / 待转写 / 已就绪"状态徽章。
4. 视频材料状态会先经历 "待转写"，转写完成后才能"生成题目"。

### 1.2 题目维护

- 已生成题目可在"题库列表"按"知识点 / 难度 / 题型"筛选。
- 单题可编辑、删除、加入收藏题集。

## 2. 考试中心（`/training/exam-center`）

- 创建考试：选择题集/材料 → 自动组卷 → 设置受众、时间、及格分。
- 系统自动判分（简答题由 LLM 协助评分，HR 复核）。
- 不及格员工自动进入"补考队列"。

## 3. 在岗培训（`/training/on-job`）

针对一线/系统实操类培训，按"节点链"管理：

- 每个节点配置：名称、时长、负责导师、材料类型（视频/操作手册/SOP/无）、**是否需学员确认**。
- 当前节点状态卡显示"进行中 / 等待学员确认 / 已完成"。
- **学员确认机制**（解决"导师未通知到学员"的痛点）：
  - 节点开启 `需要确认` 后，导师点"推进"会被拦截。
  - 出现黄色提示卡，提供两个按钮：
    - **二次提醒** — 再次钉钉推送学员
    - **学员确认** — 由学员本人在该卡片上点击确认
  - 确认后才允许"推进到下一节点"。
- 全部节点完成后自动归档到培训记录。

## 4. 培训记录（`/training/records`）

- 按员工 / 课程 / 时间筛选所有培训与考试记录。
- 可导出为该员工的"培训档案"作为转正/晋升依据。

## 最佳实践

- 高管视频培训建议时长不超过 20 分钟，AI 出题效果更好。
- SOP 类材料每次更新后请"重新生成题目"，保证题库与最新流程一致。
- 在岗培训中，关键节点（如系统实操、安全操作）务必勾选"需要确认"，避免培训走过场。
