# 员工档案 · 使用指南

> 入口：左侧菜单"员工档案"

## 1. 员工列表（`/employee/employees`）

- **筛选维度**：在职状态、合同主体、部门、归属地、关键字（姓名/工号/手机）。
- **警示标签**：列表中红色徽章标注"合同到期 / 身份证到期 / 钉钉缺数据 / 学信网未认证"，点击可跳转处理。
- **批量操作**：勾选后可批量导出、批量打标签。

## 2. 新建员工（`/employee/employees/new`）

1. 选择"录入方式"：
   - **手动录入**：分四步填写（基本信息 → 合同 → 学历 → 紧急联系）。
   - **AI 识别**：上传身份证 + 简历，自动回填，人工核对后保存。
   - **钉钉同步**：从钉钉通讯录拉取后微调。
2. 必填项标 `*`，身份证号会实时校验唯一性与位数。
3. 保存成功后自动生成工号并发送入职通知。

## 3. 员工详情（`/employee/employees/:id`）

左侧基本信息卡，右侧 Tab：

- **基础信息** — 全部字段可编辑（HR 权限）
- **合同与证件** — 显示倒计时；到期前 60 天高亮
- **材料附件** — 拖拽上传，按"身份证/合同/学历/其他"分类，已认证打绿勾
- **变动记录** — 调岗、调薪、转正流水
- **关联数据** — 一键跳转到该员工的考勤/绩效/培训

## 4. 警示中心（`/employee/alerts`）

四张卡片：合同到期、身份证到期、钉钉数据缺失、学信网未认证。

- 每张卡片可按"剩余天数"排序。
- 点击"提醒"通过钉钉推送给员工本人 + HR。
- 提醒后状态变为"已通知"，避免重复打扰。

## 5. 钉钉同步（`/employee/sync`）

- 显示上次同步时间、本次差异（新增/变更/离职）。
- 点击"立即同步"手动触发；同步过程中页面进度条实时更新。
- 差异列表支持逐条审核后写入。

## 最佳实践

- 每月初固定跑一次"警示中心 → 合同到期"，提前 30 天与员工面谈续签。
- 离职员工不要直接删除，使用"状态变更为离职"，材料保留以备审计。
- 学历字段如选择"全日制"，要求上传学信网认证截图，否则会进警示。
