# 知识库 · 使用指南

> 入口：左侧菜单"知识库"

知识库为全员提供统一的"制度 / 流程 / FAQ / 模板"查询入口，支持全文检索与 AI 智能问答。

## 1. 文档上传（`/knowledge/upload`）

- 仅 HR 可上传。支持 PDF / Word / Markdown，单文件最大 50MB。
- 必填：标题、分类（制度 / 流程 / FAQ / 模板 / 其他）、生效日期。
- 上传后状态：`待解析 → 已索引`。索引完成后才会出现在搜索结果中。
- 同名文档上传时会提示"是否作为新版本"，旧版本会保留并标记为"历史版本"。

## 2. 全文检索（`/knowledge/search`）

- 输入关键字，支持空格分隔多词（AND 关系）。
- 结果按相关度排序，命中片段高亮显示。
- 可按分类、上传时间、版本筛选。
- 点击结果直接定位到 PDF/Word 内对应页码。

## 3. 智能问答（`/knowledge/qa`）

- 用自然语言提问，例如：
  - "试用期最长多久？"
  - "出差住宿标准是多少？"
  - "年假怎么计算？"
- AI 基于知识库内容生成答案，**必须附带引用来源**（点击可跳到原文）。
- 答案右上角显示"置信度"，低于 60% 时建议改用全文检索人工核实。
- 历史问答会保存在右侧栏，可继续追问形成对话。

## 最佳实践

- 文档命名规范：`【分类】文档名 v版本号` —— 例 `【制度】员工手册 v3.2`。
- 制度更新后应"上传新版本"而非删除旧版，便于审计追溯。
- 智能问答给出的答案如发现错误，请联系 HR 核对原文档；不要直接修改 AI 回答。
- 个人/敏感信息（如薪资明细）请勿放入知识库——这里面向全员可读。
