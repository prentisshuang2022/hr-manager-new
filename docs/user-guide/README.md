# 用户指南 · 总览

欢迎使用 **HR AI 助手**。本系统覆盖人力资源全流程：员工档案、考勤、招聘、绩效、培训、知识库。

## 角色说明

| 角色 | 典型用户 | 主要能力 |
| --- | --- | --- |
| HR / 管理员 | HRBP、HR 经理 | 全公司数据维护、规则配置、报表查看 |
| 部门经理 | 各部门负责人 | 本部门员工/考勤/绩效查看、面试反馈、上级评 |
| 员工 | 全体员工 | 查看本人档案、提交自评、参加考试、问答检索 |

## 进入系统

1. 浏览器打开系统地址（生产：`https://hr-manager-new.lovable.app`）。
2. 使用钉钉扫码或工号 + 密码登录。
3. 首页显示"六大模块入口"卡片，点击进入对应模块。

## 通用操作

- **筛选**：列表页顶部支持多维筛选（部门、状态、关键字），筛选条件保存在 URL，可分享。
- **导出**：列表右上角"导出"按钮可下载当前筛选结果为 Excel。
- **搜索**：顶栏全局搜索（Ctrl/Cmd + K）支持跨模块跳转。
- **通知**：审批/提醒通过钉钉工作通知推送，系统内"消息中心"留存。

## 常见问题

**Q：忘记密码？**
联系本部门 HR，由其在"员工档案 → 详情"中重置；或直接钉钉扫码登录。

**Q：数据多久同步一次？**
钉钉考勤每小时增量同步；员工组织变动 T+1；绩效/培训为实时。

**Q：移动端可用吗？**
所有页面响应式适配，可用手机浏览器打开。后续会发布钉钉微应用。
